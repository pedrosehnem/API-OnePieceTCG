# API de Cartas

Projeto desenvolvido para a disciplina de Back-end.

A aplicação consiste em uma API criada com C# e .NET utilizando Minimal API, com o objetivo de realizar operações básicas de cadastro e gerenciamento de cartas do One Piece Card Game.

## Funcionalidades

- Informar que a API está no ar
- Listar cartas cadastradas
- Buscar carta por ID
- Adicionar uma nova carta
- Atualizar o nome de uma carta
- Excluir cartas
- Confirmar a exclusão de cartas

## Tecnologias utilizadas

- C#
- .NET
- Minimal API
- HTTP
- JSON

## Como executar

Clone o repositório:

```bash
git clone https://github.com/pedrosehnem/API-OnePieceTCG.git
```

Entre na pasta do projeto:

```bash
cd API-OnePieceTCG
```

Execute a aplicação:

```bash
dotnet run
```

A API ficará disponível no endereço informado pelo terminal.
